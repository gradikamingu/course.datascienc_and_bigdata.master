# course.datascience_and_bigdata.master

This repository contains the assignments, projects, and practical exercises I completed for the Data Science and Big Data courses in the Master’s program in Computer Science (AI & Data Science concentration).

It brings together Jupyter notebooks, Python scripts, example datasets and written reports that document end-to-end data workflows — from data acquisition, cleaning and exploratory analysis to feature engineering, model training, evaluation and scalable processing.

The projects illustrate supervised and unsupervised learning, model evaluation and interpretation, deep learning experiments, and big-data processing techniques (e.g., PySpark/Dask).
